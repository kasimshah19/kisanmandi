# KisanMandi Wireframes Checklist

## Public Screens
- [ ] **Landing Page (Home)**: Hero section with agricultural theme, quick intro, "Backend Status" indicator, links to login/register.
- [ ] **Login**: Simple login form (Email, Password) with a placeholder text "Phase 1".
- [ ] **Register**: Form for creating an account (Name, Email, Password) with a role selector (Farmer vs. Customer).
- [ ] **Mandi Dashboard**: Interface showing daily price trends. Includes filters (State, District, Commodity), a line chart for price history, a bar chart for comparison, and a data table.
- [ ] **Browse Products**: Product listing page with grid layout, search bar, and category filters.
- [ ] **Product Detail**: Detailed view of a single product showing image, price, farmer info, availability, and an "Add to Cart" button.
- [ ] **404 Not Found**: Simple page stating the resource doesn't exist.
- [ ] **403 Unauthorized**: Simple page for access denied.

## Customer Screens
- [ ] **Cart**: Review selected items, change quantities, show total price, and "Proceed to Checkout".
- [ ] **Checkout**: Select/add delivery address, select payment mode, and place order.
- [ ] **My Orders**: List of past and current orders with their status.
- [ ] **Order Tracking**: Visual timeline showing the status of a specific order (Placed, Accepted, Packed, Out for Delivery, Delivered).
- [ ] **Add Review**: Form to rate (1-5 stars) and comment on a completed order.

## Farmer Screens
- [ ] **Farmer Dashboard**: Overview of total sales, active products, and recent orders.
- [ ] **Add Product**: Form to list a new product (Category, Name, Description, Price, Quantity, Image upload).
- [ ] **My Products**: List of the farmer's active/inactive listings with options to edit or deactivate.
- [ ] **Incoming Orders**: List of orders received, with buttons to update status (Accept, Pack, Out for Delivery).

## Admin Screens
- [ ] **Admin Dashboard**: High-level system metrics (total users, total orders, revenue).
- [ ] **Farmer Approval**: List of pending farmer profiles to review and approve/reject.
- [ ] **Manage Users/Products/Orders/Categories**: Standard CRUD interfaces for system management.
- [ ] **Mandi Sync Logs**: Table showing the history and status of the Mandi API background sync job.
